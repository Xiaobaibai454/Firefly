## 题目描述

>平行世界的张老师依旧存在，与你的宇宙的张老师不同的是，C9178宇宙的张老师喜欢越野比赛

张老师想穿过一片丛林，终点在 $(n,m)$ 。他从 $(0,0)$ 出发，每次只能向下或向右走一格。丛林中的点记为 $(r,c)$，满足 $0 \le r \le n$、$0 \le c \le m$。

张老师的初始耐力和耐力上限都是 $E$，每走一步消耗 $1$ 点耐力。沿途有 $p$ 个补给点放着巧乐兹和雪碧：走到这些位置时，他会重新打起精神，耐力立即恢复到 $E$。另外丛林有 $q$ 个障碍点，不能进入。

移动需要遵守以下规则：

- 从 $(r,c)$ 出发，只能走到网格内的 $(r+1,c)$ 或 $(r,c+1)$。
- 出发前至少要有 $1$ 点耐力，走完这一步后扣除 $1$ 点。
- 若这一步到达补给点，扣除耐力后立即恢复到 $E$，即使刚好扣到 $0$ 也可以恢复。
- 到达终点时，剩余耐力可以为 $0$。

请你统计张老师有多少条合法路线能到达 xll 所在的位置，答案对 $998244353$ 取模。两条路线经过的网格点序列不同，就视为不同的路线。

## 输入描述

第一行包含五个整数 $n,m,E,p,q$，满足：

- $1 \le n,m \le 100$；
- $1 \le E \le 10^5$；
- $0 \le p,q \le 100$。

接下来 $p$ 行，每行包含两个整数 $r,c$，表示一个补给点。

再接下来 $q$ 行，每行包含两个整数 $r,c$，表示一个障碍点。

所有特殊点的坐标均在网格范围内，且互不相同。起点 $(0,0)$ 和终点 $(n,m)$ 均不是特殊点。

每个输入文件只有一个测试用例。

## 输出描述

输出一行一个整数，表示不同路径数对 $998244353$ 取模的结果。

## 样例 1

### 输入

    2 2 2 1 1
    1 1
    0 1

### 输出

    2

### 说明

样例 1 中，初始耐力为 $2$，补给点在 $(1,1)$，障碍点在 $(0,1)$。

合法路线有两条：

1. $(0,0) \to (1,0) \to (1,1) \to (1,2) \to (2,2)$；
2. $(0,0) \to (1,0) \to (1,1) \to (2,1) \to (2,2)$。

两条路线都会在耐力恰好耗尽时到达补给点，恢复耐力后继续前进。

## 样例 2

### 输入

    3 3 100000 0 0

### 输出

    20

### 说明

样例 2 中，没有特殊点且耐力足够，路线数为：

$$
\binom{6}{3}=20
$$

## 样例 3

### 输入

    2 2 4 0 2
    0 1
    1 0

### 输出

    0

### 说明

样例 3 中，起点旁边的两个可移动位置都是障碍点，因此没有合法路线。
## 我的代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define MOD 998244353
int n, m, E, p, q;
int a[102][102];
int mem[102][102][201];
int dp(int tx, int ty, int x, int y, int now, int e)
{
    if (x == tx && y == ty)
    {
        return 1;
    }
    if (now == 0)
    {
        return 0;
    }
    if (mem[x][y][now] != -1)
    {
        return mem[x][y][now]%MOD;
    }

    if (a[x][y] == -1)
    {
        return 0;
    }

    int s=0;

    if (x + 1 <= n && a[x + 1][y] != -1)
    {
        s += a[x+1][y] == 1 ? dp(n, m, x + 1, y, e, e) : dp(n, m, x + 1, y, now - 1, e);
    }
    if (y + 1 <= m && a[x][y + 1] != -1)
    {
        s += a[x][y+1] == 1 ? dp(n, m, x, y + 1, e, e) : dp(n, m, x, y + 1, now - 1, e);
    }

    mem[x][y][now]=s;
    return mem[x][y][now]%MOD;
}

int main()
{
    cin >> n >> m >> E >> p >> q;
    memset(mem, -1, sizeof(mem));


    for (int i = 1; i <= p; i++)
    {
        int r, c;
        cin >> r >> c;
        a[r][c] = 1;
    }
    for (int i = 1; i <= q; i++)
    {
        int r, c;
        cin >> r >> c;
        a[r][c] = -1;
    }
    E = min(E, 201);
    cout << dp(n, m, 0, 0, E, E);

}
```
