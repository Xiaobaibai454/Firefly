### 题目描述

给定长度为 n 的整数数组 a_1, a_2, ..., a_n，判断能否从三个不同的位置各取一个数，使它们的和为 0

即是存在两两不同的下标 i, j, k，满足：

a_i + a_j + a_k = 0.


### 输入描述

第一行包含一个整数 T (1 <= T <= 1000)，表示测试用例数。
每个测试用例包含两行。
第一行包含一个整数 n (3 <= n <= 5000)。
第二行包含 n 个整数 a_1, a_2, ..., a_n (-10^9 <= a_i <= 10^9)。
保证同一个输入文件中所有测试用例的 n^2 之和不超过 25 * 10^6。

### 输出描述

对于每个测试用例，输出一行。若存在满足条件的三个下标，输出 YES；否则输出 NO。

### 示例1

**输入**
```text
6
3
-1 0 1
3
1 2 3
3
-2 1 1
3
0 0 1
3
0 0 0
3
-3 1 2
```

**输出**
```text
YES
NO
YES
NO
YES
YES
```

**说明**
样例的第 1 组数据中，-1 + 0 + 1 = 0。第 3 组数据中，两个数值为 1 的元素来自不同位置，可以与 -2 一起选择。第 4 组数据只有两个 0，不能重复选择同一位置，因此不存在合法方案。
## 我的代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main ()
{
    int t;
    cin>>t;
    while(t--)
    {
        int n;
        cin>>n;
        vector <long long> a(n,0);
        for(int i=0;i<n;i++)
        {
            cin>>a[i];
        }
        sort(a.begin(),a.end());
        int k=0;
        for(int p=0;p<n-2;p++)
        {
            int r=n-1;
            int l=p+1;
            while(l<r)
            {
                int s=a[p]+a[l]+a[r];
                if(s==0)
                {
                    cout<<"YES"<<endl;
                    k=1;
                    break;
                }
                if(a[p]+a[p+1]+a[p+2]>0)
                {
                    cout<<"NO"<<endl;
                    k=1;
                    break;
                }
                if(a[p]+a[n-1]+a[n-2]<0)
                {   
                    break;
                }
                if(s>0)
                {
                    r--; 
                    continue;
                }
                if(s<0)
                {
                    l++;
                    continue;
                }
                
            }

            if(k==1)
                {
                    break;
                }
           
        }

        if(k==0)
        {
            cout<<"NO"<<endl;
        }

    }
}
```
