### 题目描述

小月正在进行零一计数游戏。给定长度为 n 的二进制字符串 s 和非负整数 k。
对于 s 的一个非空子串，分别统计其中字符 '0' 与 '1' 的数量，若这两个数量之差的绝对值恰为 k，则称这个子串合格。
请帮助小月统计合格非空子串的数量。

**【名词解释】**
子串：从原字符串中，连续的选择一段字符（可以全选、可以不选）得到的新字符串。

### 输入描述

第一行输入两个整数 n, k (1 <= n <= 2 * 10^5; 0 <= k <= n)，表示字符串长度和目标数量差。
第二行输入一个长度为 n，仅由字符 '0'、'1' 构成的字符串 s。

### 输出描述

输出一个整数，表示合格非空子串的数量。

### 示例1

**输入**
```text
3 1
001
```

**输出**
```text
4
```

**说明**
三个单字符子串的数量差绝对值都为 1。整个字符串含两个 '0' 和一个 '1'，也满足条件；两个长度为 2 的子串均不满足，因此答案为 4。

### 示例2

**输入**
```text
2 0
01
```

**输出**
```text
1
```

**说明**
只有整个字符串中的两种字符数量相等，数量差为 0，因此答案为 1。

## 我的代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k;
    string s;
    cin >> n >> k >> s;

    unordered_map<int, long long> freq;
    freq[0] = 1;  // 空前缀，方便统计从字符串开头开始的子串

    int prefix = 0;
    long long ans = 0;

    for (char c : s) {
        prefix += (c == '0' ? 1 : -1);

        if (k == 0) {
            ans += freq[prefix];
        } else {
            ans += freq[prefix - k];
            ans += freq[prefix + k];
        }

        ++freq[prefix];
    }

    cout << ans << '\n';
    return 0;
}
```
