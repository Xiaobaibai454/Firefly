### 题目描述

>时空发生了错乱，希特勒在未来引爆了世界炸弹，在爆炸的最后一分钟，你知道了解除炸弹的密码

>不幸的是，你没有时间去解除炸弹，你只能通过时光机给予过去的你最多三个数字，而炸弹的密码区间为 1 <= x <= 1000000

>现有的黑客程序可以判断 测试的密码数字大小 与 真实密码数字大小 ，但你最多只有十次机会使用黑客程序

>阻止希特勒！人类的命运掌握在你的手中！

这是一道第二次运行需要交互的通信题。
评测器选择并固定了整数 x (1 <= x <= 1000000)。第一次运行可以看到 x，但只能留下一条提示：一个 0 到 999 之间的整数。
第二次运行只看到这条提示，可以向评测器询问一个整数与 x 的大小关系，最多询问 10 次，然后必须准确回答 x。
程序会被独立启动两次。两次运行不能通过内存、文件或其他方式共享信息。使用同一份代码，根据 first 或 second 判断阶段。

### 输入描述

第一次运行输入两行：first、x。
第二次运行首先输入两行：second、h。h 是第一次输出的提示。之后每发出一次询问，再读取对应的回答。

### 输出描述

第一次运行输出整数 h (0 <= h <= 999)，作为唯一的提示，然后退出。
第二次运行询问时输出一行 `? y` (1 <= y <= 1000000)。评测器返回 0 表示 x < y，返回 1 表示 x = y，返回 2 表示 x > y。
确定答案后输出一行 `! x`。最终答案不计入询问次数。
每次输出询问或最终答案后必须换行并刷新输出缓冲区。读到 -1 或输入结束时立即退出。最终答案后结束程序，不要等待确认消息。格式错误、答案错误或询问超限均判错。

### 示例1

**输入**
```text
first
1500
```

**输出**
```text
1
```

**说明**
第一次留下提示 1。

### 示例2

**输入**
```text
second
1
1
```

**输出**
```text
? 1500
! 1500
```

**说明**
第二次询问 1500 后才收到最后一个 1，表示猜测等于隐藏整数。

### 备注

第二个样例是交互记录，不能在询问前读取回复。请通过正式提交验证两阶段流程。

## 我的代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main ()
{
    string a1="first";
    string a2="second";
    string a;
    cin>>a;
    if(a==a1)
    {
        int t;
        cin>>t;
        cout<<t%1000<<endl;
    }
    
    if(a==a2)
    {
        int ans;
        cin>>ans;

        int r=1000;
        int l=0;
        int k;

            while(r>=l)
            {
                int mid=l+(r-l)/2;
                if((mid*1000)+ans==0)
                {
                    cout<<"! 1000"<<endl;
                    return 0;
                }
                cout<<"? "<<(mid*1000)+ans<<endl;
                cin>>k;
                if(k==1)
                {
                    cout<<"! "<<(mid*1000)+ans<<endl;
                    return 0;
                
                }
                if(k==0)
                {
                    r=mid-1;
                }
                if(k==2)
                {
                    l=mid+1;
                }
                    
            }
        cout<<"! "<<(l*1000)+ans<<endl;
        return 0;
    }
}
